IF条件语句使用

标签作用：用于根据条件输出不同内容

注意：通过校验的 token 仅有比较运算符（==、!=、&gt;、&lt;、&gt;=、&lt;=）、逻辑运算符（&&、||）、取模 %、括号、逻辑非 !，以及字符串/数字/标识符；非法 token 会导致条件校验失败。实际求值只支持一个比较，或两个比较用 && / || 连接（不可混用）；括号与逻辑非无独立求值语义。

1、IF语句格 式

{pboot@if('a'=='b')}

内容1

{else}

内容2

{/pboot@if}

使用提示：

注意：使用时请将 @ 替换为冒号 : ，实际标签为 {pboot:if}…{/pboot:if}。

对于非数字类的条件均为字符串类型，请加上引号，如：{pboot@if('[list:author]'=='admin')}，但是数字类的可以不加：{pboot@if([list:i]==1)}

最多支持两个条件用 && 或 || 连接，二者不可混用：

条件并列：{pboot@if('[list:author]'=='admin' && [list:i]==1)}

条件或：{pboot@if('[list:author]'=='admin' || [list:i]==1)}

2、IF语句嵌套

{pboot@if('a'=='b')}

{pboot:2if('a'=='c')}

内容1

{2else}

内容2

{/pboot:2if}

{else}

内容3

{/pboot@if}
嵌套层级理论上不受限制，按此方式用数字依次嵌套即可。
