指定内容多选字段遍历

适用范围：全站任意地方均可使用

标签作用：用于依次输出指定内容的多选值，也可用于遍历逗号隔开的字段，如tag

1、指定内容多选遍历

{pboot:checkbox id=* field=*}

[checkbox:text]

{/pboot:checkbox}

控制参数：

id=* 内容ID号，必填，用于控制需遍历多选的内容，也可使用id={content:id}、id=[list:id]自适应当前内容及列表

field=* 字段，必填，用于控制需要遍历的字段，如扩展字段产品特色：ext_cpts

2、可使用的多选遍历标签

[checkbox:n] 序号从0开始
[checkbox:i] 序号从1开始
[checkbox:text] 文本
