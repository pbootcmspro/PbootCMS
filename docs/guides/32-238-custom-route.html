自定义路由（新版本优先使用后台 URL 设置；config/route.php 仍随包加载，主要用于二开）

标签作用：用于自定义地址路由规则，美化URL地址。

路由的定义在config/route.php中操作（程序启动时会加载该文件），多条路由之间用英文逗号隔开，编辑时请使用代码编辑器，请勿使用系统自带的记事本。 如果你使用的程序版本中不存在此文件，请从新版本中拷贝一个。支持正则捕获组与 $1、$2 等反向引用。

1、单页面路由格式

'home/about-us' => 'home/about/index/scode/1'

或带捕获组：'home/page-(\w+)' => 'home/about/index/scode/$1'

使用说明：

左侧为美化后的访问路径，右侧为系统内部路径；左侧括号捕获可在右侧用 $1、$2 引用。

例如关于我们编码为1时，访问地址会变为：http://域名/about-us.html

温馨提示：自定义中about为保留关键字，不要使用。

2、列表页路由格式

'home/news' => 'home/list/index/scode/2'

或带捕获组：'home/list-(\d+)' => 'home/list/index/scode/$1'

使用说明：

固定映射示例访问地址会变为：http://域名/news.html

捕获组示例可将 list-2 映射到栏目编码 2。

3、详情页路由格式

'home/test' => 'home/content/index/id/10'

或带捕获组：'home/article-(\d+)' => 'home/content/index/id/$1'

使用说明：

固定映射示例访问地址会变为：http://域名/test.html

捕获组示例可将 article-10 映射到内容 ID 10。
